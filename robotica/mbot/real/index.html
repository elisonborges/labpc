⚙️ Teste dos motores — rodas suspensas

Faça um teste por vez. Os comandos só são habilitados após a conexão BLE. Cada pulso dura no máximo 800 ms e envia parada em seguida.

Se houver movimento inesperado, desligue o mBot imediatamente. Não use este teste com o robô apoiado no chão.

🧭 Calibração de direção

Com as rodas suspensas, teste as combinações abaixo. Cada comando dura até 0,6 segundo. Observe para qual direção as rodas empurrariam o robô.

Não coloque o robô no chão durante esta calibração. Se algo inesperado ocorrer, desligue-o.

🎮 Controle direcional — pulsos de teste

Com as rodas suspensas, teste cada direção. Cada comando dura até 0,6 segundo, seguido de parada. Frente e ré seguem a calibração aprovada; os giros ainda precisam de validação.

Os nomes dos giros são provisórios até seu teste. Mantenha as rodas fora do chão.

📏 Sensor ultrassônico

Com o robô parado, aproxime e afaste um objeto do sensor. Selecione a porta RJ25 onde o sensor está conectado e clique para consultar a distância.

Distância: aguardando leitura

A leitura bruta é fornecida pelo robô. A estimativa calibrada (1,38 × leitura + 2,5) é provisória, baseada em três medições, e não deve ser usada para navegação autônoma. Se não houver resposta válida, consulte o relatório.

🚦 Radar de obstáculos

🎯 Missão Detectar Obstáculos

Com o robô parado e o radar ligado, aproxime ou afaste um livro para completar os três desafios. Cada alvo precisa de duas leituras consecutivas válidas.

1/3 — Posicione o obstáculo entre 35 e 50 cm.

Progresso: 0 de 3 desafios.

Os desafios usam a estimativa calibrada, ainda experimental. O robô não se movimenta sozinho.

🧩 Primeiros algoritmos — sequências

Monte uma sequência de até 8 passos. Cada movimento dura 0,5 segundo e o robô para automaticamente entre os passos. Teste primeiro com as rodas suspensas.
